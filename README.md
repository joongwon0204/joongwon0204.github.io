# JoongWon Shin

Personal academic portfolio built with Jekyll.

## Content

- `_pages/home.md`: home page
- `_pages/publications.md`: publication index
- `_pages/experiences.md`: experience index
- `_pages/notes.md`: notes index
- `_pages/cv.md`: web CV
- `_pages/page-not-found.md`: custom 404 page
- `assets/cv.pdf`: PDF CV
- `_data/profile.yml`: shared profile and research-interest data
- `_data/content_groups.yml`: experience and note category definitions
- `_publications/`: publication entries
- `_experiences/`: experience entries
- `_posts/`: note entries
