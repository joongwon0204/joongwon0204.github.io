## TL;DR
서울대 컴퓨터공학부 개발 동아리 **WaffleStudio** 세미나 파이널 프로젝트로 **Tistory 클론 코딩**을 진행했다.  
백엔드 4명, 프론트엔드 2명으로 구성된 팀에서 **iOS Frontend**를 맡아 화면 상호작용과 **백엔드 API 연동 전반**을 구현했다.

## 개요
- 프로젝트: **Tistory 클론 앱 (Wastory)**
- 구성: 백엔드 4명 / 프론트엔드 2명
- 역할: **iOS Frontend**
- 목표: 글 작성/조회 흐름을 중심으로 실제 서비스와 유사한 UX를 구현하고, 협업 기반 개발 프로세스를 경험

---

## 내가 한 일 (Role & Contribution)
- **화면 구성 및 내비게이션 흐름 구현**
  - 주요 화면 전환 구조를 잡고 사용자 동선이 자연스럽게 이어지도록 UI 흐름을 구성
- **View 상호작용 구현**
  - 입력/버튼/리스트 등 사용자 인터랙션 처리
- **API 연동 전반**
  - 백엔드 API와의 통신 로직을 연결하고 응답 데이터를 화면에 반영
- **협업 경험**
  - Git 기반 협업 과정에서 코드 구조와 커뮤니케이션의 중요성을 체감하고 개선 포인트를 학습
