## Summary
I worked on a **Tistory clone** as the final seminar project for **WaffleStudio**, a development club in the Department of Computer Science and Engineering at Seoul National University.
On a team of four backend developers and two frontend developers, I worked on the **iOS frontend**, implementing screen interactions and **backend API integration**.

---

![Application workflow]({{ '/assets/wastory_workflow.png' | relative_url }})

---

## Overview
- Project: **Tistory clone app (Wastory)**
- Team: Four backend developers and two frontend developers
- Role: **iOS Frontend**
- Goal: Build a user experience similar to the original service, centered on writing and reading posts, and gain experience with a collaborative development process

---

## Role and Contributions
- **Screen layout and navigation**
  - Implemented the main screen transitions and organized the UI flow to support a natural user journey
- **View interactions**
  - Handled user interactions with inputs, buttons, and lists
- **API integration**
  - Connected the app to backend APIs and displayed response data in the UI
- **Collaboration**
  - Learned the importance of code structure and communication through Git-based collaboration and identified areas for improvement

---

## Technologies
- Swift
- iOS (UIKit)
- REST API integration
- Git / GitHub collaboration
